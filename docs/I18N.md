# Internationalization

## How it works

Translation files are Lua files that return a nested table structure. The
i18n module (`lib/i18n.lua`) loads the appropriate file based on locale and
looks up strings by dot-separated keys.

## Adding a new language

### 1. Create the translation file

Create `i18n/<code>.lua` (e.g. `i18n/de.lua`). Copy the structure from
`i18n/en.lua` and translate all values:

```lua
return {
  dashboard = {
    title = "=== ARMATURBRETT ===",
    altitude = "Höhe",
    pressure = "Druck",
    ...
  },
}
```

### 2. Set locale in settings

In `config/settings.json`:
```json
{ "locale": "de" }
```

### 3. (Optional) Font encoding for non-ASCII

If your locale uses characters outside standard ASCII (Cyrillic, accented
Latin, etc.), you need a CC:T texture pack that provides those glyphs, plus
an encoder module. See [Font Encoding](#font-encoding) below.

## Translation file structure

```lua
return {
  dashboard = {
    title = "=== TEXT ===",
    altitude = "Alt",
    pressure = "Press",
    pitch = "Pitch",
    yaw = "Yaw",
    roll = "Roll",
    velocity = "Vel",
    velocity_magnitude = "Speed",
    rel_angle = "Rel Angle",
    x_axis = "X",
    y_axis = "Y",
    z_axis = "Z",
    trigger = "TRG",
    active = "ACTIVE",
    inactive = "off",
    altitude_hold = "ALT HOLD",
    on = "ON",
    off = "OFF",
    units = {
      meters = "m",
      kPa = "kPa",
      degrees = "\xC2\xB0",
      m_s = "m/s",
    },
  },
}
```

- Keys use dot-notation: `lang.t("dashboard.units.meters")`
- Values can contain `string.format` placeholders if needed
- `entities: \xC2\xB0 is the degree sign (°) in UTF-8

## Font Encoding

CC:T uses a bitmap font where each codepoint is drawn from a texture atlas
(16×16 grid = 256 slots). A **texture pack** replaces these slots with custom
glyphs. To display Cyrillic (or any non-ASCII) text:

1. Install a CC:T texture pack that places Cyrillic glyphs in known codepoint slots
2. Create a `lib/font.lua` encoder matching that texture pack's layout
3. Set `locale: "ru"` in settings — the display module auto-loads font encoding

### `lib/font.lua` — provided encoder

The included `lib/font.lua` encodes Cyrillic UTF-8 to CC:T codepoints for a
standard Cyrillic texture pack:

| Slot range | Characters |
|---|---|
| \191 – \223 | А – Я (uppercase, incl. Ё at \197) |
| \224 – \255, \013 | а – я (lowercase, я at \013) |

**Usage**:
```lua
local font = require("lib.font")
local encoded = font.encode("Привет")  -- returns encoded bytes

-- With display module (automatic for locale "ru"):
display.init("left", "ru")
```

### Creating a custom encoder

If your texture pack uses different codepoints, create your own `lib/font.lua`:

```lua
local myfont = {}
local map = {}
-- Map UTF-8 Cyrillic characters to your texture pack's codepoints
map["А"] = "\191"
-- ... full mapping ...

function myfont.encode(text)
  return text:gsub("([\194-\223][\128-\191])", function(seq)
    return map[seq] or seq
  end)
end

return myfont
```

The `gsub` pattern `[\194-\223][\128-\191]` matches all 2-byte UTF-8 sequences
(which includes all Cyrillic characters). Each matched sequence is looked up in
the mapping table. Non-mapped sequences pass through unchanged.

### Texture pack notes

- CC:T font texture is a 16×16 grid in `assets/computercraft/textures/gui/term_font.png`
- Each cell is 6×9 pixels in the default font
- The grid reads left-to-right, top-to-bottom: slot 0 = top-left, slot 255 = bottom-right
- Codepoints 0–31 are control characters (displayed as symbols in CC:T)
- Standard ASCII is slots 32–127
- Extended characters (for texture packs) use slots 128–255
